\begin{itemize}
  \item 資料來源：Amazon Reviews 2023

  \item 原始資料網站：\url{https://amazon-reviews-2023.github.io/}

\subsection{實際會用到的資料}

\begin{tabularx}{\textwidth}{p{0.42\textwidth}X}
\textbf{檔案} & \textbf{用途} \\
\hline
\cmd{data/reviews\_30\_20.pkl} & 主要 interaction data；RA-GARK、baseline、case study 都會用。 \\
\cmd{data/df\_edges\_item\_aspect1.csv} & 預設 item-aspect KG。 \\
\cmd{data/df\_edges\_all\_aspect1.csv} & raw KG；給 \cmd{kg\_clean.py} 產生 canonical KG。 \\
\cmd{data/kg\_canonical.csv} & canonical KG；只有 \cmd{use\_canonical\_kg=True} 或 \cmd{relation\_init/} 會用。 \\
\cmd{data/kg\_relation\_map.json} & canonical KG 的 relation mapping。 \\
\cmd{data/kg\_canonical\_report.txt} & canonical KG 清理報告。 \\
\end{tabularx}

\subsection{主要 config 參數}

\begin{itemize}
  \item \cmd{interaction\_path}：preprocess 後的 review interaction。\\
  預設為
  \cmd{data/reviews\_30\_20.pkl}。
  \item \cmd{kg\_path}：預設 item-aspect KG。預設為 \cmd{data/df\_edges\_item\_aspect1.csv}。
  \item \cmd{use\_canonical\_kg}：是否改用 canonical KG。預設為 \cmd{False}。
  \item \cmd{canonical\_kg\_path}：canonical KG path。預設為 \cmd{data/kg\_canonical.csv}。
  \item \cmd{num\_aspects}：aspect slots 數量。預設為 \cmd{4}。
  \item \cmd{embedding\_dim}：embedding 維度。預設為 \cmd{128}。
  \item \cmd{eval\_k}：Top-K evaluation 的 K。預設為 \cmd{20}。
\end{itemize}

\section{資料前處理}

目前 repo 裡的主資料已經 preprocess 完成，可直接訓練。接手時先確認 \cmd{Code/data/} 內資料都存在，再依照以下順序執行。

\subsection{Preprocess 做的事情}

\begin{itemize}
  \item 過濾 review interaction，只保留可用資料。
  \item 依照 \cmd{like} 欄位保留 positive interactions 作為推薦訓練資料。
  \item 重新 label encode user 與 item，產生 \cmd{user\_idx}、\cmd{item\_idx}。
  \item 使用 user-stratified split 切分 train、validation、test。
  \item 使用 \cmd{data/df\_edges\_item\_aspect1.csv} 建立 item-aspect KG。
  \item KG 會移除高頻 noisy aspects 與 \cmd{Config.kg\_stopwords}。
\end{itemize}

\subsection{如果要重建 canonical KG}

\begin{verbatim}
python kg_clean.py
\end{verbatim}

輸出：

\begin{itemize}
  \item \cmd{data/kg\_canonical.csv}
  \item \cmd{data/kg\_relation\_map.json}
  \item \cmd{data/kg\_canonical\_report.txt}
\end{itemize}

\section{實驗執行流程}

\subsection{執行 RA-GARK}

\begin{verbatim}
python train_ragark.py
\end{verbatim}

輸出結果為 RA-GARK 的主模型實驗結果。

\subsection{執行消融實驗}

快速版：

\begin{verbatim}
python run_ablations.py --mode minimal --reuse
\end{verbatim}

論文表格版：

\begin{verbatim}
python run_ablations.py --mode paper --reuse
\end{verbatim}

sensitivity：

\begin{verbatim}
python run_ablations.py --mode sensitivity --reuse
\end{verbatim}

輸出：

\begin{itemize}
  \item \cmd{results/ablation\_results\_<mode>.csv}
  \item \cmd{runs/archive/}
  \item \cmd{runs/best/}
  \item \cmd{runs/best\_ledger.json}
\end{itemize}

\subsection{執行 Baseline 模型}

\begin{verbatim}
python run_main_benchmark.py
\end{verbatim}

會執行：

\begin{itemize}
  \item MCCLK
  \item KGCL
  \item KGAT
  \item KGRec
  \item LightGCN
  \item RA-GARK
\end{itemize}

輸出：

\begin{itemize}
  \item \cmd{results/main\_benchmark\_results.csv}
  \item \cmd{runs/archive/main\_benchmark\_results\_<timestamp>.csv}
\end{itemize}

\subsection{Case Study}

\begin{verbatim}
python case_study.py
\end{verbatim}

用途：觀察同一商品在不同 user 下的 rationale aspect attention 是否不同。

輸出：

\begin{itemize}
  \item \cmd{results/case\_study.txt}
  \item \cmd{results/case\_study.csv}
\end{itemize}

\section{注意事項}

\begin{itemize}
  \item 不要任意覆蓋 \cmd{runs/best/} 或 \cmd{runs/best\_ledger.json}。
  \item \cmd{relation\_init/} 是 archived experiment，除非要重訪 canonical KG initialization branch，否則不建議修改。
  \item 若只想確認環境，跑 \cmd{smoke\_test.py}。
  \item 若要正式實驗數字，跑 \cmd{run\_ablations.py} 或 \cmd{run\_main\_benchmark.py}。
\end{itemize}
