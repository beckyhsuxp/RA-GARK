\section{程式碼架構}

本專案主要程式位於 \texttt{Code/}。所有 Python 指令建議都從
\texttt{Code/} 目錄執行，避免相對路徑如 \texttt{data/reviews\_30\_20.pkl}
無法正確解析。

\begin{verbatim}
Code/
    config.py
    data.py
    kg_loader.py
    model.py
    losses.py
    evaluate.py
    utils.py
    train_ragark.py
    run_ablations.py
    run_main_benchmark.py
    case_study.py
    smoke_test.py
    data/
    baselines/
    relation_init/
    results/
    runs/
    handoff/
\end{verbatim}

\begin{longtable}{p{0.28\textwidth}p{0.62\textwidth}}
\textbf{路徑} & \textbf{用途} \\
\hline
\texttt{config.py} & 集中管理資料路徑、模型參數、訓練參數與消融開關。 \\
\texttt{data.py} & 載入互動資料、建立 KG index、建立 LightGCN adjacency。 \\
\texttt{kg\_loader.py} & canonical KG 載入器，只有 canonical KG 實驗或檢查工具會用到。 \\
\texttt{model.py} & RA-GARK 模型本體。 \\
\texttt{losses.py} & BPR loss 與 contrastive loss。 \\
\texttt{evaluate.py} & Top-K 評估指標計算。 \\
\texttt{train\_ragark.py} & RA-GARK 主模型訓練與測試。 \\
\texttt{run\_ablations.py} & 消融實驗與 sensitivity 實驗。 \\
\texttt{run\_main\_benchmark.py} & Baseline 與 RA-GARK 的主比較實驗。 \\
\texttt{case\_study.py} & rationale attention 的案例分析。 \\
\texttt{smoke\_test.py} & 快速檢查環境、資料、模型 forward/backward 與 evaluator 是否可跑。 \\
\texttt{baselines/} & KGAT、KGCL、KGRec、MCCLK 等 baseline 實作。 \\
\texttt{relation\_init/} & archived canonical-KG initialization experiment，除非重跑該分支，否則不建議修改。 \\
\texttt{results/} & 最新 CSV/TXT 結果，供論文表格或人工檢查使用。 \\
\texttt{runs/} & 實驗 checkpoint、best ledger 與 archive。 \\
\end{longtable}

\section{Environment Setting}

此專案沒有在 \texttt{Code/} 內固定提供完整環境檔。交接時建議先在目標機器
安裝專案所需 Python 套件，再用 smoke test 確認環境是否可用。

\begin{verbatim}
cd Code
python smoke_test.py
\end{verbatim}

\texttt{smoke\_test.py} 只用於確認環境與主要程式路徑沒有壞掉，不是正式實驗，
也不是論文數字的來源。若缺少套件，程式會提示缺少的 Python dependency。

\section{Dataset}

\subsection{主要資料}

目前實際訓練預設會使用以下兩個檔案：

\begin{itemize}
  \item \texttt{data/reviews\_30\_20.pkl}：互動資料，為所有 RA-GARK、baseline 與 case study 的主要 interaction input。
  \item \texttt{data/df\_edges\_item\_aspect1.csv}：預設 KG，對應 \texttt{Config.kg\_path}。
\end{itemize}

\subsection{canonical KG 相關資料}

以下檔案主要用於 canonical KG 實驗、KG 清理流程或 audit：

\begin{itemize}
  \item \texttt{data/df\_edges\_all\_aspect1.csv}：raw KG input，供 \texttt{kg\_clean.py} 使用。
  \item \texttt{data/kg\_canonical.csv}：canonical KG，當 \texttt{use\_canonical\_kg=True} 時使用。
  \item \texttt{data/kg\_relation\_map.json}：raw relation 到 canonical relation 的 mapping。
  \item \texttt{data/kg\_canonical\_report.txt}：canonical KG 清理報告。
\end{itemize}

\section{執行流程}

執行前請先確認目前工作目錄為 \texttt{Code/}。

\subsection{環境與資料快速檢查}

正式實驗前建議先執行：

\begin{verbatim}
python smoke_test.py
\end{verbatim}

此步驟會檢查必要 data 檔案、預設 KG 建立、模型 forward/backward，以及一小批
Top-K evaluation。通過後再執行正式實驗。

\subsection{執行 RA-GARK 主模型}

\begin{verbatim}
python train_ragark.py
\end{verbatim}

此指令會以 \texttt{config.py} 中的預設設定訓練 RA-GARK，並在 validation
上選擇 best checkpoint 後進行 test evaluation。

\subsection{執行消融實驗}

最小檢查版：

\begin{verbatim}
python run_ablations.py --mode minimal --reuse
\end{verbatim}

論文表格版本：

\begin{verbatim}
python run_ablations.py --mode paper --reuse
\end{verbatim}

sensitivity 實驗：

\begin{verbatim}
python run_ablations.py --mode sensitivity --reuse
\end{verbatim}

消融實驗輸出會寫入：

\begin{itemize}
  \item \texttt{results/ablation\_results\_<mode>.csv}
  \item \texttt{runs/archive/}
  \item \texttt{runs/best/}
  \item \texttt{runs/best\_ledger.json}
\end{itemize}

\subsection{執行 Baseline 模型}

\begin{verbatim}
python run_main_benchmark.py
\end{verbatim}

此腳本會依序執行 baseline 與 RA-GARK 主模型比較，包含：

\begin{itemize}
  \item MCCLK
  \item KGCL
  \item KGAT
  \item KGRec
  \item LightGCN
  \item RA-GARK
\end{itemize}

主要輸出：

\begin{itemize}
  \item \texttt{results/main\_benchmark\_results.csv}
  \item \texttt{runs/archive/main\_benchmark\_results\_<timestamp>.csv}
\end{itemize}

\subsection{執行 Case Study}

\begin{verbatim}
python case_study.py
\end{verbatim}

此腳本用於輸出 rationale attention 的可解釋性案例。主要輸出：

\begin{itemize}
  \item \texttt{results/case\_study.txt}
  \item \texttt{results/case\_study.csv}
\end{itemize}

\section{結果檔案對應}

\begin{longtable}{p{0.35\textwidth}p{0.55\textwidth}}
\textbf{檔案} & \textbf{說明} \\

\end{longtable}

\section{注意事項}

\begin{itemize}
  \item 不要任意覆蓋 \texttt{runs/best/} 或 \texttt{runs/best\_ledger.json}，除非明確要重跑並更新 best-run ledger。
  \item \texttt{relation\_init/} 是 archived reproducibility material，除非要重訪 canonical KG initialization 分支，否則不建議修改。
  \item 若只想確認環境，請執行 \texttt{smoke\_test.py}；若要取得論文正式數字，請使用 \texttt{run\_ablations.py} 或 \texttt{run\_main\_benchmark.py}。
  \item 所有實驗建議從 \texttt{Code/} 目錄執行。
\end{itemize}
